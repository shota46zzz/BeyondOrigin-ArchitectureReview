# White Castle — Preliminary Window and Palette Specification

Status: DESIGN_ONLY

- Primary walls: white concrete, quartz bricks, polished diorite.
- Standard window: `minecraft:light_gray_stained_glass_pane`.
- Great Hall / Throne Arena accents: `minecraft:light_blue_stained_glass_pane` and sparingly `minecraft:blue_stained_glass_pane`.
- Optional clear windows: `minecraft:glass_pane`.
- Frames: `minecraft:quartz_bricks`, `minecraft:quartz_stairs`, `minecraft:quartz_slab`.
- **Prohibited for windows:** `minecraft:iron_bars`. Any special-use exceptions need explicit approval.
- Main roof silhouette: dark, steeply pitched roof material to be chosen during design review; no specific block finalized yet.
- Gothic windows: large hall 9–13 blocks tall; upper rooms 4–6; towers 3–6; avoid identical window spacing across all facades.
